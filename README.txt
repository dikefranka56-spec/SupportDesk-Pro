# SupportDesk Pro – Customer Support Ticket Management System

SupportDesk Pro is a web-based customer support management application designed to help businesses organize, manage, and resolve customer enquiries and complaints efficiently.

The platform provides a centralized ticket management system where customers can submit support requests, support agents can manage and respond to tickets, and administrators can oversee support activities.

### Key Features
- User registration and secure login
- Customer support ticket submission
- Ticket tracking and status management
- Admin, agent, and customer roles
- Ticket communication and message management
- Centralized database management

### Technologies Used
- PHP
- MySQL
- HTML5
- CSS3
- JavaScript

### Project Purpose
The goal of SupportDesk Pro is to improve customer service operations by reducing manual support processes, organizing customer enquiries, and making issue resolution more structured and efficient.
