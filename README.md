## Overview

**Support Desk Pro** is a full-stack customer support and ticket management platform designed to help businesses organize customer inquiries, manage support requests, and improve communication between customers and support teams.

The application provides a centralized environment where customers can create accounts, submit support tickets, describe their issues, track submitted requests, and communicate through ticket-based conversations.

It also provides dedicated management interfaces for organizing support activities and managing team members.

Built with PHP, MySQL, HTML, CSS, and JavaScript, SupportDesk Pro demonstrates practical full-stack development through authentication, database integration, ticket management, and interactive application interfaces.

## Application Workflow

1. Customers visit the SupportDesk Pro website.
2. New users register, while existing users log in.
3. Users access the support dashboard.
4. Customers create support tickets describing their issues.
5. Submitted tickets become available for support management.
6. Customers and support representatives communicate through ticket replies.
7. Ticket information is updated as support requests progress.

## Installation & Setup

### Requirements

- PHP.
- MySQL.
- Apache Web Server.
- XAMPP.
- Modern web browser.

### Local Installation

**1. Clone or download the repository**

Download the project from GitHub and extract it into your XAMPP `htdocs` directory.

**2. Project directory**

```text
C:\xampp\htdocs\SupportDesk-Pro\
```

**3. Start Apache and MySQL**

Open XAMPP Control Panel and start both services.

**4. Create the database**

Open phpMyAdmin:

```text
http://localhost/phpmyadmin
```

Create the required database and import `database.sql`.

**5. Configure the database**

Open `config.php` and configure the database connection details to match your local MySQL environment.

**6. Launch the application**

Visit:

```text
http://localhost/SupportDesk-Pro/
```
